# PlayRealm

Games you know, rules you don’t: 57 free browser games, each with one fresh twist.

**Play: https://vipinyadavz.github.io/playrealm/**

This folder is the built site, ready for static hosting. It is generated by `tools/build.js` from the PlayRealm source; edit the source and build again rather than changing these files.

No accounts, no ads, no tracking: see [privacy.html](privacy.html). Works offline once opened, with a keyboard, a controller or touch.
